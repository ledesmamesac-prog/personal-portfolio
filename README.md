## 🛠️ Tecnologías

Este proyecto está construido **desde cero** (from scratch), evadiendo frameworks pesados para maximizar la velocidad de carga y mantener un control absoluto sobre cada píxel de la interfaz.

* **HTML5** Semántico estructurado para SEO.
* **CSS3** Puro (sistema de variables dinámicas y diseño adaptativo).
* **JavaScript (Vanilla)** Modular, sin dependencias, basado en ES6+.

## ✨ Características

* 🌓 **Dynamic Theme Toggle:** Implementación de Modo Oscuro/Claro con guardado local y una transición gráfica avanzada mediante máscara recíproca (*ripple expansion*).
* 🖱️ **Custom Cursor:** Interacciones animadas a lo largo de toda la UI con seguimiento progresivo (`requestAnimationFrame`).
* 📜 **Scroll Reveal:** Animaciones desencadenadas en tiempo visualización real optimizadas con `IntersectionObserver`.
* 📱 **Mobile First:** Menú *off-canvas* y layouts tipo tarjeta apilada diseñados para verse increíbles desde cualquier smartphone.
* 📄 **Visor PDF Integrado:** Modal superpuesto con bloqueo de scroll de fondo, evitando que las descargas re-dirijan al usuario.

## 🚀 Desarrollo local

Dado que es una estructura web nativa (`.html`, `.css`, `.js`), no hay necesidad de usar gestores de paquetes.

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ledesmamesac-prog/personal-portfolio.git
   ```
2. Entra al directorio del proyecto:
   ```bash
   cd personal-portfolio
   ```
3. Lánzalo al navegador. (Recomendado: Extensión **Live Server** de VSCode para hot-reload).
